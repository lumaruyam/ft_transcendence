## Stack

- **Build tool**: Vite 8, MPA mode (one HTML entry point per page)
- **Language**: Vanilla TypeScript — React is used **only** for the whiteboard page (Excalidraw requirement)
- **Output**: `frontend/dist/` — generated by `vite build`, served by nginx as static files

## Route → source mapping

| URL | Source folder | Notes |
|---|---|---|
| `/` | `frontend/src/landing/` | Public landing page |
| `/login` | `frontend/src/login/` | Email/password login |
| `/signup` | `frontend/src/signup/` | Account creation |
| `/forgot-password` | `frontend/src/forgot-password/` | Password reset request |
| `/auth/callback` | `frontend/src/auth-callback/` | OAuth2 redirect handler (GitHub/GitLab) |
| `/invite/:token` | `frontend/src/invite/` | Invite link acceptance |
| `/settings` | `frontend/src/settings/` | User profile & account settings |
| `/app` | `frontend/src/dashboard/` | Project list (requires auth) |
| `/app/:id` | `frontend/src/kanban/` | Kanban board for a project |
| `/app/:id/settings` | `frontend/src/project-settings/` | Project settings (name, members, danger zone) |
| `/app/:id/whiteboard` | `frontend/src/whiteboard/` | Excalidraw whiteboard — **React + `@excalidraw/excalidraw`** |
| `/app/:id/notes` | `frontend/src/notes/` | Shared notes (Tiptap) |
| `/legal/privacy` | `frontend/src/legal/privacy/` | Privacy Policy |
| `/legal/terms` | `frontend/src/legal/terms/` | Terms of Service |
| 404 | `frontend/src/not-found/` | Served by nginx `error_page 404` |
| 502 / 503 / 504 | `frontend/src/error/` | Served by nginx `error_page 502 503 504` (backend down) |

Each page folder contains:
- `index.html` — HTML entry point (loaded by Vite, references `main.ts`)
- `main.ts` (or `main.tsx` for whiteboard) — page-specific logic, imports from `src/api/`, `src/shared/`, `src/auth/` etc.

## Nginx routing logic

- **Exact routes** (`/`, `/login`, `/app`, `/settings`, …) → served via `location = /path`
- **Dynamic routes** (`/app/:id`, `/app/:id/whiteboard`, …) → matched by regex `location ~ ^/app/[^/]+$`
- **Dynamic ID extraction** → done in JS via `window.location.pathname.split('/')[2]`; nginx never parses the ID
- **404** → `error_page 404 /not-found/index.html`
- **Backend down** → `error_page 502 503 504 /error/index.html`
- **Backend proxy** → `/api/` and `/socket.io/` forwarded to `backend:3000`; lazy-resolved via Docker DNS (`resolver 127.0.0.11`) so nginx starts even if the backend container is not up

## React version constraint

React is pinned to `^18` in `package.json`. `@excalidraw/excalidraw` 0.17.x declares
`peerDependencies: react@"^17.0.2 || ^18.2.0"` and is incompatible with React 19.
**Do not upgrade `react` / `react-dom` past 18.x** without first verifying Excalidraw
compatibility. See `_note_react` in `package.json`.
